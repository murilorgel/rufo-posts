# rufo-posts

Artes e calendário de publicação do Instagram da Rufo.

- `midia/`: imagens em JPEG servidas pelo link público para a API do Instagram.
- `calendario.json`: posts, horários (America/Sao_Paulo) e legendas.
- `publicar.py`: publica os posts vencidos via graph.instagram.com. O token não fica no repositório.
